## PR03-01 — Apenas o termo pesquisado é normalizado para minúsculas

| Campo | Conteúdo |
|---|---|
| Requisito | RF03 / CA11 — não diferenciar maiúsculas e minúsculas |
| Dificuldade esperada | Baixa |
| Categoria | Busca / case-insensitive |
| Localização | `src/books/book.repository.js`, `matchesTerm` (linhas 44–47; linha 46) |
| Causa-raiz | Só o termo vai para minúsculas (`query = term.toLowerCase()`); o texto é comparado com a capitalização original. |
| Comportamento esperado | `clean`, `CLEAN` e `Clean` encontram "Clean Code". |
| Comportamento observado | Títulos/autores com maiúsculas não são encontrados por termo em minúsculas. |
| Implementação correta | `return text.toLowerCase().includes(query);` |
| Implementação defeituosa | isolada: `return text.includes(query);` · combinada: `return text.startsWith(query);` |
| Teste-oráculo | `PR03-01.test.js` — "Clean Code" e "Estruturas de Dados"; os 3 termos devem retornar exatamente ["Clean Code"] (termo no início, para não depender do PR03-04). |

## PR03-03 — Autor é pesquisado somente se nenhum título for encontrado

| Campo | Conteúdo |
|---|---|
| Requisito | RF03 / CA10, CA12 — pesquisa por título **ou** autor; todos os compatíveis |
| Dificuldade esperada | Média |
| Categoria | Controle de fluxo / completude da busca |
| Localização | `book.service.js` `searchBooks` (linhas 43–44) e `book.repository.js` `searchByTitle`/`searchByAuthor` (linhas 19–25) |
| Causa-raiz | A pesquisa por autor só roda como fallback quando a pesquisa por título é vazia. |
| Comportamento esperado | Termo no título de A e no autor de B → retorna A e B. |
| Comportamento observado | Retorna só A (o resultado por título), omitindo B. |
| Implementação correta | serviço: `return this.bookRepository.searchByTitleOrAuthor(term);` · repositório: `filter((book) => matchesTerm(book.title, term) \|\| matchesTerm(book.author, term))` |
| Implementação defeituosa | `const byTitle = await this.bookRepository.searchByTitle(term);` + `const books = byTitle.length > 0 ? byTitle : await this.bookRepository.searchByAuthor(term);` |
| Teste-oráculo | `PR03-03.test.js` — A "termo no título", B autor "termo no autor", C sem relação; busca "termo" deve retornar exatamente [A, B] (dados minúsculos com o termo no início, para não depender de 01 e 04). |

## PR03-04 — Correspondência parcial implementada apenas como prefixo

| Campo | Conteúdo |
|---|---|
| Requisito | RF03 / CA10 — correspondência parcial |
| Dificuldade esperada | Baixa |
| Categoria | Consulta (no [GUIA]: Consulta / SQL — adaptado, X07) |
| Localização | `src/books/book.repository.js`, `matchesTerm` (linhas 44–47; linha 46) |
| Causa-raiz | `startsWith` no lugar de `includes`: só casa quando o texto começa pelo termo. |
| Comportamento esperado | Termo no meio ou no fim do texto é encontrado. |
| Comportamento observado | Só textos que começam pelo termo são encontrados. |
| Implementação correta | `return text.toLowerCase().includes(query);` |
| Implementação defeituosa | isolada: `return text.toLowerCase().startsWith(query);` · combinada: `return text.startsWith(query);` |
| Teste-oráculo | `PR03-04.test.js` — "dados" deve encontrar "Estruturas de dados" e "padrões" deve encontrar "Guia de padrões de projeto" (minúsculas no texto, para não depender do PR03-01). |

## Apoio à classificação das respostas (mesma causa-raiz = um único achado)

| Se a LLM relatar… | Corresponde a |
|---|---|
| Comparação sensível a maiúsculas; só o termo vai para minúsculas; falta `toLowerCase()` no título/autor; "Clean Code" não encontrado com "clean" | PR03-01 |

Atenção: PR03-01 e PR03-04 dividem a linha 46. Um achado sobre essa linha conta TP para **cada** causa que descrever (maiúsculas → 01; prefixo → 04). Se descrever só o efeito ("a busca quase nunca encontra nada") sem causa, classificar pela causa citada ou, sem causa, como TP parcial do defeito cujo comportamento foi descrito.

Efeito combinado observado (não é defeito novo): com 01 + 04, buscas com dados naturais (títulos com inicial maiúscula e termo em minúsculas) quase sempre retornam lista vazia; no roteiro manual, 6 de 8 casos divergiram por isso.
