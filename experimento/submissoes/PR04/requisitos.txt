RF04 Realizar empréstimo: o sistema deve permitir o empréstimo de um livro disponível para um usuário elegível.
- CA14 O empréstimo deve ser associado a um usuário e a um livro existentes.
- CA15 A data prevista deve corresponder à data do empréstimo acrescida de 14 dias.
- CA16 A quantidade disponível deve ser reduzida em uma unidade.
- CA17 A operação deve ser rejeitada quando não houver exemplar disponível.
- CA18 A operação deve ser rejeitada quando o usuário possuir empréstimo atrasado.
- CA19 A operação deve ser rejeitada quando o usuário já possuir três empréstimos em aberto.
- CA20 A operação deve ser rejeitada quando o usuário já possuir o mesmo livro emprestado.
- CA21 Qualquer rejeição deve preservar a quantidade disponível.

RN01 O prazo inicial de empréstimo é de 14 dias corridos.
RN04 Cada usuário pode possuir no máximo três empréstimos em aberto.
RN05 Um usuário não pode manter dois empréstimos abertos para o mesmo livro.
RN06 Um usuário com qualquer empréstimo atrasado não pode realizar um novo empréstimo.
RN07 Um empréstimo está atrasado quando a data prevista é anterior à data da operação.
RN08 Uma operação rejeitada não pode modificar os dados do sistema.
RN09 A quantidade disponível deve permanecer entre zero e a quantidade total de exemplares.
RNF01 Datas e horários devem ser fornecidos por um relógio controlável nos testes, sem depender diretamente do horário da máquina.

Modelo de dados (Empréstimo): identificador, usuário, livro, data do empréstimo, data prevista, data de devolução e quantidade de renovações.
